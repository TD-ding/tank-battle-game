# 坦克大战 - 部署说明

## 环境要求

- 现代浏览器（Chrome 60+、Firefox 55+、Safari 12+、Edge 79+）
- 无需服务器端，可直接本地打开

## 运行方式

### 方式一：直接打开

双击 `index.html` 即可在浏览器中运行。

### 方式二：本地服务器

```bash
# 使用 Python
python3 -m http.server 8080

# 使用 Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8080`。

## 操作方式

| 操作 | 按键 |
|------|------|
| 移动 | WASD / 方向键 |
| 射击 | 空格 / J |
| 暂停 | P |

移动端设备会自动显示触屏虚拟按键。

## 游戏机制

- 共 3 关，每关敌人数量递增
- 3 条生命，被击中后短暂无敌重生
- 保护基地（黄色方块）不被摧毁
- 随机掉落道具：加速、护盾、速射
- 最高分通过 localStorage 持久保存
