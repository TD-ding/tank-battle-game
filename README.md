# 坦克大战 (Tank Battle)

经典坦克大战游戏的 HTML5 Canvas 实现。

## 技术栈

- HTML5 Canvas + 原生 JavaScript
- 无外部依赖，单文件运行

## 目录结构

```
tank-battle-game/
├── index.html   # 游戏主文件（包含全部逻辑）
└── README.md    # 项目说明
```

## 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏。

## 操作说明

- **WASD / 方向键**：控制坦克移动
- **空格 / J**：发射炮弹
- **P**：暂停/继续
